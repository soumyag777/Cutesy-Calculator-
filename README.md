# ✿ Cutesy Calculator ✿

A soft, pastel calculator with a little blob buddy who reacts to your math. Vibe coded and designed for mobile first.

🌸 **[Try it live](https://soumyag777.github.io/Cutesy-Calculator-/)**

## What makes it cute
- 🫧 **A mascot with feelings:** blinks while you type, smiles when you hit =, and gets shocked if you divide by zero ("oopsie!")
- 🎀 **Pastel palette:** pink, lavender, and baby blue, with squishy buttons that press down when you tap them
- 📱 **Mobile first:** sized for thumbs, no zooming, and comfy on phone or iPad
- ⌨️ **Keyboard friendly:** numbers, + − × ÷, Enter for =, Backspace, and Esc to clear

## Features
- Add, subtract, multiply, and divide
- Percent, backspace, and all clear
- Decimal handling, so no "1.2.3" mistakes
- Friendly error state instead of "Infinity" or "NaN"

## Built with
HTML, CSS, and vanilla JavaScript in one file, so there are no frameworks or installs. The font is [Fredoka](https://fonts.google.com/specimen/Fredoka). It's hosted on GitHub Pages.

## Design notes
I wanted a utility app that feels like a little friend instead of a tool. The mascot gives instant emotional feedback: a happy face confirms a result, and a shocked face turns an error into a soft moment instead of a cold one.
